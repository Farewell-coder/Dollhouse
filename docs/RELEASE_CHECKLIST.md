## ⚠️ 先读：验证时最容易踩的坑（会骗你做出错误结论）

**`uiautomator dump` 给的不是布局边界，是无障碍边界。**
Compose 会把**小于 48dp** 的语义节点以元素中心为基准，**对称外扩到 48dp**。

```
布局值 = dump值 ∓ (48dp − 元素实际尺寸) / 2        // 左/上减，右/下加
```

- 实测代价：我把 36dp 头像的 dump `x=30` 误判成"顶栏左移 6dp"，白查一轮（见文末「已证伪」）。
- **正确做法**：要判「布局有没有真的偏」，就量同一行里**一个 ≥48dp 的元素**（卡片边缘、搜索框、输入框）。
- 量小图标、小药丸的位置 → **一定是假偏移**。
