# Dollhouse 全局优化实施清单

> 基线：`v0.2.5`（versionCode 25），2026-11-06。
> 本文是执行记录，不代表每项已经完成；完成项必须对应提交、测试或真机验收。

## 原则

- 不破坏已有功能、协议、数据结构和签名升级路径。
- 先可靠性、可读性与性能，再新增陪伴与生态能力。
- 每项有边界、验证方式和回退方式；不因动画牺牲操作效率。
- 高风险设备操作、敏感配置与外部服务必须保持授权与确认。
- 每批独立 CI，通过后合并；发布版本另行确认。

## 阶段一：UI 基础与可靠性

### UI-01 排版与尺寸
- 统一标题、正文、说明、按钮的字号与行高。
- 多行文字设置行高；单行紧凑标签不强制行高。
- 大字体、窄屏下避免固定高度与溢出。
- 验证：聊天、人偶、设置、导入页截图矩阵。

### UI-02 命中区与视觉尺寸分离
- 保留孤立图标最小命中区。
- 药丸/完整按钮不得被 48dp 下限拉成长椭圆。
- 输入框尾部图标不撑高父容器，文字垂直居中。
- 验证：所有 `pressable` / `minTouchTarget` 高风险调用点。

### UI-03 流畅与反馈
- 长列表惰性渲染、稳定 key、必要时条目动画。
- 统一按压、加载、成功、失败反馈与防重复触发。
- 帧率分级，后台停止非必要动画。
- 转场克制、滚动边界自然、嵌套手势不冲突。
- 验证：CI + 真机滚动/展开/键盘/返回路径。

### REL-01 模型适配向导
- 检查端点、鉴权、模型列表和协议能力。
- 推荐默认模型；失败给明确原因与修复建议。
- 不要求用户理解 `/v1`、Responses、max_tokens 等细节。
- 验证：真实合法端点、错误地址、错误 Key、无模型、候选路径。

### REL-02 聊天可靠性
- 请求状态、超时/失败分类、有限重试、停止与续发。
- 流式中断保留已收到正文，不重复扣费、不重复工具副作用。
- 诊断导出不得泄漏 Key 或正文。
- 验证：网络中断、停止、超时、HTTP 4xx/5xx、流式异常。

## 阶段二：角色生态与记忆

### MODEL-01 多模态模型包
- 统一静态图、帧序列、动图、Lottie 的清单、预览与回滚。
- 引擎不支持的格式在导入前明确拒绝，不留下不可播放记录。
- 验证：官方测试包、缺文件、错误引擎、覆盖与回滚。

### BEHAVIOR-01 行为编排
- 待机、点击、拖动、聊天、夜间、低电量等行为的优先级模板。
- 实时预览；不改变现有默认行为。
- 验证：动作冲突、中断、恢复、低功耗。

### MEM-01 记忆工作台
- 事实、偏好、承诺、待办分类；来源、纠正、合并、删除、置顶。
- 图谱不是唯一入口；普通列表可读可检索。
- 验证：写入、修改、删除、检索、隐私边界。

### VISION-01 本地图片与文件理解
- OCR、截图问答、文本摘要、引用、分块与取消。
- 处理过程不静默上传；仅发给用户配置的模型服务。
- 验证：长文、非文本、取消、失败恢复。

## 阶段三：安全、陪伴与生态

### DEVICE-01 设备操作安全沙盒
- 计划预览、风险分级、白名单、单次确认、敏感步骤二次确认。
- 可回滚操作优先提供回滚；不可逆操作不得自动执行。
- 验证：未授权、服务停止、命令失败、拒绝执行。

### BACKUP-01 完整备份
- 配置、会话、记忆、人偶、主题、动作包统一版本化备份。
- 恢复前展示差异；敏感配置加密或明确排除。
- 验证：缺项、旧版本、损坏包、覆盖确认与回滚。

### COMPANION-01 陪伴节奏
- 首次见面、常用话题、安静时段、纪念日与轻量问候。
- 默认不打扰；不伪造情绪或记忆。
- 验证：通知、夜间、后台恢复与取消。

### ECOSYSTEM-01 插件化动作与人格包
- 本地包来源、版本、权限、兼容性与回滚。
- 不做未经审核的远程自动执行内容。
- 验证：签名/来源、版本冲突、导入失败与恢复。

## 交付节奏

1. UI-01 / UI-02 / UI-03：独立提交、CI、真机验收。
2. REL-01 / REL-02：独立提交、网络故障测试。
3. MODEL-01 / MEM-01：资源与记忆兼容性测试。
4. BEHAVIOR-01 / VISION-01：交互与后台恢复。
5. DEVICE-01 / BACKUP-01：安全审查与恢复演练。
6. COMPANION-01 / ECOSYSTEM-01：低打扰与包安全审查。
